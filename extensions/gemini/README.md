# Gemini AI

Access Google's Gemini AI directly from Vicinae. Ask questions, get answers, and chat with Gemini — all without leaving your workspace.

## Configuration

Before using the extension, you need to set up your Gemini API key:

1. Get an API key from [Google AI Studio](https://ai.studio/api-keys).
2. In Vicinae, open the extension preferences for **Gemini AI**.
3. Enter your API key in the **Gemini API Key** field.

### Model Selection

By default, the extension uses `gemini-3.5-flash-lite`. You can change the model at any time:

- Use the **Select Model** command to quickly open the settings.
- Choose from the available free-tier models in the **Gemini Model** dropdown:
  - Gemini 3.8 Flash
  - Gemini 3.6 Flash
  - Gemini 3.5 Flash Lite (default)
  - Gemini 3.1 Flash Lite
  - Gemini 3 Flash Preview

## Commands

| Command | Description |
|---|---|
| **Ask Low** | Ask Gemini with minimal thinking — fast, concise responses. |
| **Ask Medium** | Ask Gemini with balanced thinking — a mix of speed and depth. |
| **Ask High** | Ask Gemini with deep thinking — thorough, detailed reasoning. |
| **Ask in Browser** | Search with Google AI in your browser. |
| **Open Chat** | Open the Gemini web chat interface in your browser. |
| **Select Model** | Open extension settings to change the Gemini model. |
