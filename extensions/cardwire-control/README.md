# Cardwire and ASUS

Control [Cardwire](https://github.com/OpenGamingCollective/cardwire) GPU modes and [asusd](https://github.com/flukejones/asusctl) platform power from Vicinae.

Requires the `cardwire` and `asusctl` CLIs on PATH. You can set custom binary paths in extension preferences.

Dev:

```bash
npm install
npm run dev
```

Build:

```bash
npm run build
```
