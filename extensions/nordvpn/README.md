# NordVPN

Control the NordVPN Linux app from Vicinae.

# Requirements
- nordvpn installed on your machine
- A nordvpn account
- Sign in to your nordvpn account

# Interface

- **NordVPN** — connection status and every country; Enter on a country lists its cities.
- **Connect NordVPN** — connect to the fastest server.
- **Disconnect NordVPN** — disconnect.
