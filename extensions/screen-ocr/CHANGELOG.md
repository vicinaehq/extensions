# Changelog

## [1.1.1] - 2026-11-09

### Added

- **Recognize Text**: select an area of the screen with GNOME's screenshot UI and copy the recognized text.
- **Recognize Text from Clipboard**: run OCR on an image in the clipboard (e.g. after Print Screen).
- **Recognize Text Fullscreen**: run OCR on the whole screen.
- **Detect Barcode / QR Code**: decode a QR code or barcode in a selected area.
- Preferences for OCR languages, line breaks, capture method, 2x upscaling and keeping screenshots.
